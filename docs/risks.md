# Risk register

**F** = established source fact; **I** = architectural inference; **Q** = measurement/open question. Priorities are ordered around stable residency, not speed.

| Risk / status | Consequence and detection | Initial control / resolving milestone |
|---|---|---|
| **MLX lazy graph/COW lifetime (F mechanism, Q contribution to reported stall)** | Pending slice updates, `mx.depends`, retained views/generators/compiled closures can keep old buffers or computation alive. Look for active bytes exceeding page accounting, completion delays and allocations after every append. | M1 compares output-only, all-state eval and ds41f-style async/eval/synchronization boundaries with private tails and deliberately retained lazy outputs/views; bounded evaluated tails and scalar-only diagnostics. Add minimal native storage only if needed. |
| **Growing contiguous relocation (F)** | Current caches concatenate on capacity growth; old/new buffers and pending graphs can coexist. Trimming does not shrink storage. | M3 independent blocks, no sealed-prefix replacement, release unreferenced tail pages after completion. Measure physical behavior, not object identity alone. |
| **512 GB resident headroom (F payload, Q actual)** | Main expert payload alone ~338.82 GiB; side vectors, dense representations and OS consume additional capacity. | **DSA selected-row gather (F interface, Q new adapter)** | Wrong absolute/page offsets, order, scale/bias row, duplicate padding or invalid causal lengths corrupt attention. | **Blockwise top-k precision/ties (I)** | Changed reduction ordering can perturb near-tied indices; per-page full K and many small launches may cost throughput. | Preserve FP32 accumulation, absolute causal positions and exact candidate merging; numerical tie-aware comparison. | **Native ABI/build constraints (F)** | Sparse MLA requires particular heads/dims/dtypes/layouts, selected-row dimension `K >= 16`, and the multi-query fast path; q4 affine projections do not consume EXLR8 bitstreams. | **Incomplete state commit / lookahead (F reference patterns, I runtime hazard)** | Sampling a token need not evaluate unused indexer writes; visible output and consumed frontier can diverge. Suspended generation can retain one step ahead. | One transaction, no initial lookahead; materialize every changed state; explicit consumed/pending-token accounting. M3/M4. |
| **Cancel/exception/non-release (I/Q)** | Partially mutated layers are not resumable; exception tracebacks or client generators can retain full session arrays. ## Strong conclusions versus unresolved questions

**Established:** full/shared semantics exist; exact EXLR8 operators exist; selected-row latent dequantization exists; current cache capacity growth uses concatenation; MLXLR8 resident optimizations can change weights; ds41f explicitly controls state completion and transient handles.

**Strong inference:** a small owned runtime with independent fixed blocks, conservative evaluation and bounded scratch is a better fit for long sessions than inheriting the general generator/cache stack. Resident exact packed up1 with a useful floating-cache context appears feasible.

**Unresolved:** precise GLM-5.3 stall cause; whether private MLX tails donate storage reliably under the adopted call pattern; actual target residency/load/scratch budget; best page grouping; useful q8 error tolerance and long-context effects; native build compatibility. Resolve with narrow experiments, not a new semantic-proof program.
